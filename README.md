"# DengueWatch." 
Campus DengueWatch is a web-based system that helps a university campus prevent
and respond to dengue. Users report mosquito activity on an interactive map (Leaflet),
and the reports appear as a heatmap of hotspots. The system has four user types:
Guest, User (Logged In), Admin and Authority.
It is made up of several fairly independent modules: reporting and heatmap, a symptoms
questionnaire with a medical help portal, cleanup events, and Admin/Authority actions
(moderation, assigned field work, mitigation action pins, advisories)
